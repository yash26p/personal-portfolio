# Personal Portfolio Website

A responsive personal portfolio website developed using HTML5, CSS3, and Bootstrap 5. The website presents my profile, skills, projects, and contact information in a clean and professional design.

## 👨‍💻 About

This portfolio website is created to showcase my academic background, technical skills, projects, and interests as an Information Technology student.

## 🚀 Features

- Responsive navigation bar
- Personal introduction section
- About Me section
- Technical Skills section
- Featured Projects section
- Contact form
- Responsive design for desktop, tablet, and mobile devices
- Bootstrap 5 integration
- Custom CSS styling
- JavaScript functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
